# Instrucciones Post-Venta

Cuando un cliente compre un plan, sigue estos pasos:

## 1. Confirmación de pago

PayPal te enviará una notificación cuando se complete el pago.

## 2. Envía email al cliente

Tema: `Bienvenido a Binance Skills Hub Pro`

Contenido base:

```
Hola [Nombre],

Gracias por comprar el plan [Starter/Pro/Enterprise] de Binance Skills Hub Pro.

Tu pago ha sido confirmado. Aquí están tus datos de acceso:

📦 Plan: [Starter/Pro/Enterprise]
💰 Monto: $[29/99/499]
📅 Válido por: 1 mes

👉 PRÓXIMOS PASOS:

1. Accede al repositorio: https://github.com/luisjhz89-svg/binance-skills-hub
2. Sigue la guía de instalación: https://github.com/luisjhz89-svg/binance-skills-hub/blob/main/INSTALLATION.md
3. Consulta la documentación de tu skill elegido

📞 SOPORTE:
Para ayuda, escribe a: Estudiolegalqro26@icloud.com

Queremos que disfrutes el producto. Si tienes dudas, estamos aquí.

Saludos,
Binance Skills Hub Pro Team
```

## 3. Gestión de acceso

- Para Starter: proporciona acceso a 1 skill específico
- Para Pro: acceso completo a todos los skills
- Para Enterprise: agrega al repositorio privado + onboarding call

## 4. Seguimiento

- Envía email de bienvenida dentro de 24 horas
- Revisa que el cliente haya completado la instalación en 48 horas
- Ofrece soporte si hay preguntas

## 5. Reembolsos

Si solicitan reembolso dentro de 7 días:

- Verifica la fecha de compra
- Revisa si cumple con la política de reembolso
- Procesa el reembolso en PayPal
- Envía confirmación al cliente
