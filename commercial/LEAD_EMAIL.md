# Seguimiento de lead por correo

## Objetivo

Convertir un lead en cliente con una respuesta profesional y útil en menos de 24 horas.

## Mensaje de bienvenida

```
Hola [Nombre],

Gracias por tu interés en Binance Skills Hub Pro.

Hemos recibido tu solicitud y queremos ayudarte a encontrar el plan ideal para tu caso de uso.

Para avanzar, te pedimos responder estas preguntas:

1. ¿Eres usuario individual, desarrollador o empresa?
2. ¿Qué skill te interesa más?
3. ¿Cuál es tu caso de uso principal?
4. ¿Necesitas soporte para integración o solo instalación?

Con esta información, te recomendaremos el plan correcto y te enviaremos la propuesta más adecuada.

Puedes responder este correo o escribirnos directamente a:

Estudiolegalqro26@icloud.com

Gracias por contactarnos.

Saludos,
Binance Skills Hub Pro Team
```

## Flujo recomendado

1. El cliente llena el formulario de lead.
2. Se responde en menos de 24 horas.
3. Se confirma si es usuario, desarrollador o empresa.
4. Se recomienda el plan adecuado.
5. Se comparte propuesta y precio.
6. Se cierra venta o se agenda una llamada de diagnóstico.
